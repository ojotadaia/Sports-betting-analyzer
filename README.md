# ⚽ Analisador de Apostas Esportivas - Futebol

Um analisador profissional de apostas esportivas focado em futebol, com dados reais do mercado de apostas brasileiras e análise dos maiores cassinos do mundo.

## 🎯 Características Principais

### 1. **Analisador de Apostas** 📊
- Análise de partidas de futebol com odds reais do mercado
- Cálculo de probabilidades para cada resultado
- Estatísticas detalhadas de times e jogadores
- Previsões baseadas em análise estatística
- Insights estratégicos para tomada de decisão

**Dados inclusos:**
- Flamengo vs Palmeiras (Campeonato Brasileiro)
- Real Madrid vs Barcelona (La Liga)
- Liverpool vs Manchester City (Premier League)

## 🚀 Como Usar

### Instalação

```bash
# Clonar ou acessar o diretório do projeto
cd sports_betting_analyzer

# Instalar dependências
npm install

# Iniciar o servidor de desenvolvimento
npm run dev
```

O servidor estará disponível em `http://localhost:5173/`

### Navegação

1. **Abra a aplicação** no navegador
2. **Selecione uma seção** usando os botões de navegação:
   - 📊 Analisador de Apostas
   - 📈 Dados do Mercado
   - 🎰 Análise de Cassinos

3. **Explore os dados:**
   - Selecione diferentes partidas no analisador
   - Visualize tendências do mercado
   - Compare cassinos interativamente
